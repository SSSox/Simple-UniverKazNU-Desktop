# Политика конфиденциальности

Simple Univer для Windows: неофициальное приложение для сайта [univer.kaznu.kz](https://univer.kaznu.kz/). У приложения нет своего сервера и учётных записей. Разработчик не получает никаких ваших данных: ни пароля, ни оценок, ни сведений об использовании.

## Чего в приложении нет

- аналитики, телеметрии, счётчиков использования и рекламы;
- отправки отчётов о сбоях;
- проверки обновлений и других запросов к серверам разработчика;
- передачи данных третьим лицам.

## Куда приложение обращается по сети

| Куда | Когда и что |
| --- | --- |
| `https://univer.kaznu.kz` | Всё, что вы делаете в кабинете, как в обычном браузере. Кроме этого приложение само: входит с сохранёнными логином и паролем через форму сайта, читает в фоне разделы кабинета для уведомлений и «Дистанционных курсов» (только чтение, не чаще раза в 10 минут) и скачивает файлы, которые вы выбрали |
| Ваш браузер по умолчанию | Внешние ссылки, на которые вы нажали, и переход в Moodle из раздела «СДО Moodle»: адрес перехода выдаёт сайт Univer |
| Серверы, с которых сайт сам загружает ресурсы | Страницы Univer могут подключать картинки, видео или скрипты с других сайтов; это решает сайт, как и в любом браузере |
| `download.microsoft.com`, `download.visualstudio.microsoft.com` | Только установщик и только если на компьютере нет .NET Framework или Visual C++ и вы согласились их скачать |

Встроенный Chromium запускается с отключённым обновлением компонентов и без журналов.

## Что хранится на компьютере

Всё хранится только локально, в профиле вашей учётной записи Windows:

| Что | Где | Что внутри |
| --- | --- | --- |
| Данные входа | `%LOCALAPPDATA%\Univer.Desktop\credentials.dpapi` | Логин и пароль, зашифрованные Windows DPAPI: расшифровать их может только ваша учётная запись Windows на этом компьютере |
| Настройки | `%LOCALAPPDATA%\Univer.Desktop\preferences.json` | Язык, тема, вид, масштаб, размер окна, трей, закреплённые ссылки (до 24), отметка «не показывать предупреждение Legacy», пауза автовхода. Без пароля |
| Список загрузок | `%LOCALAPPDATA%\Univer.Desktop\downloads.json` | Имена, пути, размеры и даты скачанных файлов и курс, из которого файл скачан; вместо адреса файла хранится его хеш. Без cookies |
| Уведомления | `%LOCALAPPDATA%\Univer.Desktop\notices.json` | Названия пунктов меню, анкет со сроками и тексты сообщений сайта, отметки «прочитано». Без паролей и значений форм |
| Профиль браузера | `%LOCALAPPDATA%\Univer.Desktop\Browser-Modern` (Modern) или `Browser` (Legacy) | Cookies сессии, кэш и хранилище сайта Univer, как у обычного браузера |
| Скачанные файлы | Ваша папка «Загрузки» | Файлы, которые вы скачали |

В папке программы (установленной или portable) личных данных нет. Установщик кладёт туда только файл `installation-id.txt` с названием варианта (например, `Univer.Desktop.modern.x64`), чтобы обновление попало в ту же папку.

## Как удалить данные

- **Выйти из аккаунта** («Настройки → Аккаунт»): удаляет cookies и хранилище сайта, заменяет профиль браузера, автовход останавливается. Сохранённый пароль остаётся до удаления.
- **Удалить данные входа** («Настройки → Аккаунт»): удаляет зашифрованную запись и завершает сессию; список уведомлений тоже очищается.
- **Убрать из списка** в «Загрузках»: убирает запись, сам файл остаётся в папке «Загрузки».
- **Удалить всё**: удалите программу через «Параметры → Приложения», затем папку `%LOCALAPPDATA%\Univer.Desktop`. Удаление программы само эту папку не трогает, чтобы обновление и переустановка не теряли вход.

Удалённые файлы удаляются обычным способом Windows: гарантированного стирания с диска (особенно с SSD) и из резервных копий Windows нет. Выход в приложении не завершает сессии на других устройствах.

## Ваши данные на сайте

Оценки, расписание, анкеты и другие данные кабинета хранит университет на своём сайте; приложение только показывает их. За обработку этих данных отвечает КазНУ им. аль-Фараби по своим правилам.

## Изменения

Изменения этой политики видны в истории этого файла в репозитории. Вопросы можно задать в issues репозитория; уязвимости сообщайте закрыто, как описано в [SECURITY.md](SECURITY.md).
