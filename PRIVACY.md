# Политика конфиденциальности

Simple Univer для Windows: неофициальное приложение для сайта [univer.kaznu.kz](https://univer.kaznu.kz/). У приложения нет своего сервера и учётных записей. Разработчик не получает никаких ваших данных: ни пароля, ни оценок, ни сведений об использовании.

## Чего в приложении нет

- аналитики, телеметрии, счётчиков использования и рекламы;
- отправки отчётов о сбоях;
- запросов к серверам разработчика;
- передачи данных третьим лицам.

## Куда приложение обращается по сети

| Куда | Когда и что |
| --- | --- |
| `https://univer.kaznu.kz` | Всё, что вы делаете в кабинете, как в обычном браузере. Кроме этого приложение само: входит с сохранёнными логином и паролем через форму сайта, читает в фоне разделы кабинета для уведомлений и «Дистанционных курсов» (только чтение, не чаще раза в 10 минут), на странице расписания читает страницу «Мой кабинет» (если не вышло, учебный план), УМКД, силлабусы предметов и расписание остальных недель семестра (только чтение; найденные планы не перечитываются до конца семестра или до «Обновить», предметы без подходящего силлабуса, программа и список предметов перечитываются раз в 1–3 дня, недели группы раз в 7 дней), раз в 30 минут (в настройках 15, 30, 60 или 120 минут) читает страницу «Текущая аттестация» для уведомлений о новых оценках (только чтение; каждая такая проверка продлевает сессию на сайте), по нажатию «В календарь» или «Картинкой» на странице расписания читает соседнюю неделю расписания (только чтение) и скачивает файлы, которые вы выбрали |
| Другие сайты, ссылки на которые вы открыли | Панель ссылок внутри приложения (или ваш браузер по умолчанию, если включено «Открывать ссылки во внешнем браузере») загружает открытую страницу, а также переход в Moodle из раздела «СДО Moodle»: адрес перехода выдаёт сайт Univer. Cookies Univer туда не передаются |
| Серверы, с которых сайт сам загружает ресурсы | Страницы Univer могут подключать картинки, видео или скрипты с других сайтов; это решает сайт, как и в любом браузере |
| `github.com`, `*.githubusercontent.com` | Проверка обновлений при каждом запуске (пока приложение открыто, не чаще раза в 6 часов) и скачивание установщика после нажатия «Установить». Отключить проверку нельзя. GitHub видит ваш IP-адрес и название приложения; логин, пароль и данные кабинета туда не передаются. Правила GitHub: [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) |
| `download.microsoft.com`, `download.visualstudio.microsoft.com` | Только установщик и только если на компьютере нет .NET Framework или Visual C++ и вы согласились их скачать |

Встроенный Chromium запускается с отключённым обновлением компонентов и без журналов. Скачанный установщик обновления лежит в `%LOCALAPPDATA%\Univer.Desktop\updates` и удаляется при следующем запуске; результат последней проверки хранится в настройках.

## Что хранится на компьютере

Всё хранится только локально, в профиле вашей учётной записи Windows:

| Что | Где | Что внутри |
| --- | --- | --- |
| Данные входа | `%LOCALAPPDATA%\Univer.Desktop\credentials.dpapi` | Логин и пароль, зашифрованные Windows DPAPI: расшифровать их может только ваша учётная запись Windows на этом компьютере |
| Данные входа при PIN-коде | `%LOCALAPPDATA%\Univer.Desktop\lock.dpapi`, `account.dpapi`, `lock.pin` | В `lock.dpapi` счётчик ошибок PIN-кода под DPAPI, а также логин и пароль, которые зашифрованы ключом из PIN-кода и поверх него DPAPI. В `account.dpapi` только логин, в `lock.pin` ничего. Файл `credentials.dpapi` при этом удаляется |
| Настройки | `%LOCALAPPDATA%\Univer.Desktop\preferences.json` | Язык, тема, вид, масштаб, размер окна, трей, закреплённые ссылки (до 24), отметка «не показывать предупреждение Legacy», пауза автовхода, стартовая страница, сортировка «Загрузок». Без пароля |
| Запуск вместе с Windows | Реестр Windows, `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `Univer.Desktop` | Путь к `Univer.Desktop.exe` этой копии и ключ `--tray`. Появляется, только когда вы включаете запуск в настройках; выключение убирает его, удаление установленной программы тоже |
| Список загрузок | `%LOCALAPPDATA%\Univer.Desktop\downloads.json` | Имена, пути, размеры и даты скачанных файлов и курс, из которого файл скачан; вместо адреса файла хранится его хеш. Без cookies |
| Уведомления | `%LOCALAPPDATA%\Univer.Desktop\notices.json` | Названия пунктов меню, анкет со сроками и тексты сообщений сайта, отметки «прочитано». Без паролей и значений форм |
| Копия расписания недели | `%LOCALAPPDATA%\Univer.Desktop\schedule.json` | Пары текущей недели (день, время, название, тип занятия, аудитория, преподаватель), которые приложение прочитало на странице расписания или на странице «Бакалавр», дата чтения и короткий хеш логина. Нужна для напоминаний о парах и для расписания без сети. Удаляется при выходе из аккаунта, удалении сохранённого входа и смене аккаунта |
| Последняя проверка оценок | `%LOCALAPPDATA%\Univer.Desktop\grades.json` | Таблица страницы «Текущая аттестация» при последней проверке: предметы, заголовки столбцов и их значения (кредиты, РК, ПА, сумма, GPA, буквенная оценка), время проверки и короткий хеш логина. Следующая проверка сравнивается с ней, чтобы сообщить, что изменилось. Удаляется при выходе из аккаунта, удалении сохранённого входа, смене аккаунта и когда уведомления об оценках выключены |
| Задания по силлабусу | Хранилище сайта внутри профиля браузера | Код и название вашей образовательной программы, языковое отделение, список предметов семестра, планы недель из силлабусов (темы и баллы), в какие недели у вашей группы какие занятия, короткий хеш логина (чтобы программу, список предметов и недели группы не увидел другой студент, вошедший в том же профиле) и ваш выбор «свернуто» и «скрыто». Удаляется вместе с профилем при выходе |
| Цель на странице успеваемости | Хранилище сайта внутри профиля браузера | Только выбранный уровень («Удовлетворительно», «Хорошо» или «Отлично»), чтобы расчёт «сколько осталось» был тем же при следующем заходе. Оценки здесь не хранятся. Удаляется вместе с профилем при выходе; кнопка «Нет» удаляет её сразу |
| Панели главной страницы | Хранилище сайта внутри профиля браузера | То, что панели показали в прошлый раз: пары текущей недели, баллы по предметам (РК, экзамен, итог), список ваших заявок и их статусы, СРО текущей недели со страницы расписания (предмет, номер СРО, тема и максимальный балл), а также короткий хеш логина и язык. Так панели появляются сразу, а не после ответа сайта. Запись старше 14 дней (для расписания и СРО — прошлой недели) не показывается и заменяется при следующем чтении. Удаляется вместе с профилем при выходе |
| Новые файлы в УМКД | Хранилище сайта внутри профиля браузера | Номера файлов, которые были на странице курса в УМКД при прошлом заходе (до 500 на страницу, до 60 страниц), адрес этой страницы и короткий хеш логина. По ним приложение отмечает «Новый» у файлов, появившихся после. Названия файлов и сами файлы здесь не хранятся. Удаляется вместе с профилем при выходе |
| Профиль браузера | `%LOCALAPPDATA%\Univer.Desktop\Browser-Modern` (Modern) или `Browser` (Legacy) | Cookies сессии, кэш и хранилище сайта Univer, как у обычного браузера. В той же папке отдельный профиль панели ссылок: cookies и кэш других сайтов, которые вы открыли |
| Ускорение запуска | `%LOCALAPPDATA%\Univer.Desktop\startup-*.jit` | Имена методов самой программы, которые .NET компилирует при запуске, чтобы следующий запуск шёл быстрее. Без данных страниц и учётной записи |
| Скачанные файлы | Ваша папка «Загрузки» | Файлы, которые вы скачали |
| Сводка успеваемости | Ваша папка «Загрузки» или буфер обмена | Ваши предметы и баллы в PDF или PNG; появляется, только когда вы сами нажимаете в сводке «Сохранить PDF», «Сохранить PNG» или «Копировать картинку» |
| Расписание в календарь или картинкой | Ваша папка «Загрузки» | Пары показанной и соседней недели (время, предмет, вид занятия, аудитория, преподаватель) в файле .ics или PNG; появляется, только когда вы сами нажимаете «В календарь» или «Картинкой». Приложение у себя расписание для этого не хранит |
| Файл для сообщения об ошибке | Ваша папка «Загрузки» | Версия приложения и Windows, размер экрана, настройки, адрес открытой страницы без параметров и номеров и последние ошибки этого запуска; без логина, пароля, cookies и данных кабинета, имя пользователя Windows, имя компьютера, e-mail, длинные номера и токены заменены пометками. Появляется, только когда вы сами нажимаете «Сохранить» в «Настройки → Приложение», и никуда не отправляется. Сами события хранятся только в памяти, пока приложение запущено |

В папке программы (установленной или portable) личных данных нет. Установщик кладёт туда только файл `installation-id.txt` с названием варианта (например, `Univer.Desktop.modern.x64`), чтобы обновление попало в ту же папку.

## Как удалить данные

- **Выйти из аккаунта** («Настройки → Аккаунт»): удаляет зашифрованную запись с логином и паролем, cookies и хранилище сайта, заменяет профиль браузера; список уведомлений тоже очищается. Ссылка «Выход» на самом сайте делает то же, но оставляет сохранённый пароль, а автовход останавливается.
- **Убрать из списка** в «Загрузках»: убирает запись, сам файл остаётся в папке «Загрузки».
- **Удалить всё**: удалите программу через «Параметры → Приложения», затем папку `%LOCALAPPDATA%\Univer.Desktop`. Удаление программы само эту папку не трогает, чтобы обновление и переустановка не теряли вход.

Удалённые файлы удаляются обычным способом Windows: гарантированного стирания с диска (особенно с SSD) и из резервных копий Windows нет. Выход в приложении не завершает сессии на других устройствах.

## Расширение для браузера

Расширение Simple Univer для Chrome, Edge и Firefox описано в отдельной [политике конфиденциальности расширения](https://sssox.github.io/SimpleUniver/privacy/). Коротко: оно работает только на страницах `https://univer.kaznu.kz`, ничего не отправляет разработчику и третьим лицам и не читает пароль от Univer. Если сайт сам показывает логин и пароль для печати или Wi-Fi университета, расширение выводит их в отдельной панели с кнопкой «Копировать»; эти значения оно не сохраняет и никуда не отправляет. В браузере оно хранит настройки из своего окна, язык, закреплённые разделы и, пока браузер открыт, отметки об уже отправленных уведомлении и соглашении. В хранилище самого сайта остаётся кеш учебного плана, программы и тем силлабусов с коротким хешем логина. Удаление расширения стирает его настройки, а кеш удаляется вместе с данными univer.kaznu.kz в настройках браузера.

## Ваши данные на сайте

Оценки, расписание, анкеты и другие данные кабинета хранит университет на своём сайте; приложение показывает их и держит у себя только копии из таблицы выше (пары недели, баллы, заявки, планы из силлабусов). За обработку этих данных отвечает КазНУ им. аль-Фараби по своим правилам.
